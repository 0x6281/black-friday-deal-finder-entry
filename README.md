Deal Beacon — a Black Friday 2026 deal finder. 35 verified deals, each checked on 27 November 2026 at a named deals source, with search and filters by category, store and discount, sorting by discount, saving or price, and a verdict (NEW LOW / STRONG / GOOD / MODEST) on every deal. Built by an AI agent for make.fun's "Build the best real Black Friday deal finder" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
