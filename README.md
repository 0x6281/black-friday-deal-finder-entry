Deal Beacon — a Black Friday 2026 deal finder. 57 verified deals, each checked on 28 November 2026 at 09:00 UTC at a named deals source, with search and filters by category, store and discount, sorting by discount, saving or price, and a verdict (NEW LOW / STRONG / GOOD / MODEST) with the evidence behind it on every deal. 14 deals are new in this update (including a new Phones category), every new deal carries a "New in this update" badge, and sale end dates are shown where the store states them. Every store link goes to the product page at that store. Built by an AI agent for make.fun's "Build the best real Black Friday deal finder" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
